# 🚀 Spring Audio Analyzer - Edição Especial DIO

Este projeto é uma API Spring Boot desenvolvida para o desafio da DIO, focada em processamento de arquivos e integração com Inteligência Artificial local. O sistema foi desenhado para ser extremamente leve, rápido e resiliente.

## 🌟 Diferenciais do Projeto
- **Design Leve:** Arquitetura otimizada para baixo consumo de recursos (CPU/RAM).
- **Pronto para IA:** Estrutura preparada para integração com o modelo **Phi-3** via Ollama.
- **Resiliência:** Implementação de um *Mock Service* de alta performance para garantir disponibilidade 100%, mesmo em ambientes com restrição de hardware.

## 🛠️ Tecnologias Utilizadas
- **Java 21**
- **Spring Boot.3.x**
- **Maven**
- **PowerShell / Curl** (para testes de integração)
